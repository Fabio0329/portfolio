## Overview

My personal site: a home page with a short intro and what I'm working on now,
an About page, a blog of posts that teach what I'm learning, and write-ups of projects
like this one. It's fully static, so there are no servers, databases, or API
keys to keep running.

## What's on it

- **Home:** intro, an "In progress" block, featured projects, and recent blog posts
- **Blog:** learn-with-me posts on topics like accessibility, with an RSS feed
- **Projects:** write-ups like this one, each with its stack and links
- **About:** background, skills, and a link to my resume
- **Extras:** light and dark themes, generated link-preview images for every
  page, and a sitemap

## How it works

```text
content/blog/*.mdx
content/projects/*.mdx
          │
          ▼
@next/mdx (build time)
          │
          ▼
static HTML + RSS
          │
          ▼
Vercel CDN
```

- **Content is files in the repo.** Posts and project write-ups are MDX
  files, reviewed in git like code. One module (`lib/content`) is the only
  code that knows where they live.
- **Everything is built ahead of time.** At build time Next.js compiles the
  MDX, checks each file's metadata, and pre-renders every page. Visitors get
  plain HTML, so there's nothing to break at request time.
- **Bad content fails the build, not the page.** A post with missing metadata
  stops the deploy instead of going live half filled.
- **Drafts** show locally and stay off the live site.
- **Theming** runs on a small set of color tokens, so a redesign is mostly a
  token change.

## Testing and deployment

- **Every change goes through a pull request.** CI runs lint, type checks,
  unit tests, a production build, and accessibility tests, and a red check
  blocks the merge. Vercel deploys whatever lands on `main`.
- **Accessibility is tested, not just reviewed.** Strict accessibility lint
  rules, an axe check on every component, a test that every color pair meets
  WCAG contrast in both themes, and axe on every built page (drafts included)
  in light and dark mode at desktop, 375px, and 320px.
- **Guardrails for my AI coding agent.** I build with Claude Code, so the repo
  lints every file it edits and won't let it finish a task until the full
  check suite passes.
- **Results:** 104 unit and component tests and 24 page-level tests in a real
  browser, and Lighthouse 100 in performance, accessibility, best practices,
  and SEO on every public page, on mobile and desktop, at launch.
